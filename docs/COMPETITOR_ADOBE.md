# Competitor learnings — Adobe (adobe.com)

Studied: adobe.com homepage (2026-08) + Lightroom / Photography plans + Adobe blog culling GA + market pricing/churn.  
LensOS stance: **do not replace Adobe craft** — own **card → pick → handoff → client link**.

---

## What Adobe’s homepage is selling right now

| Slot | Promise | Primary CTA |
|------|---------|-------------|
| **Creative Cloud** | “Create at the highest level.” | Free trial |
| **Firefly** | “All the best models, all in one place.” | Create with Firefly |
| **Acrobat** | “Get work done. Faster.” | Free trial |
| **Business** | “Orchestrate customer experiences with AI.” | It starts with Adobe |
| **Education** | Students/teachers save ~71% | Free trial |

**Structure (steal the pattern, not the sprawl):**
1. Product router marquee (video/UI proof)
2. Outcome tiles — one line each
3. “Explore what’s new” feature drops (AI Assistant, Premiere Color Mode, Brand Visibility)
4. Named creator testimonials → **See all plans**
5. News strip + full product grid (Firefly, Acrobat, PS, Premiere, CC, GenStudio, Illustrator…)

Adobe’s site is **not a single product page**. It’s a **catalog + free-trial machine**: big promise → product tiles → social proof → plans → trial.

**Homepage bias (2026):** Firefly + AI sit *above* pure photography. Lightroom is not the hero of adobe.com — **platform + gen AI + Acrobat + enterprise** are. Photographers are a *segment*, not the homepage.

---

## What adobe.com does well (steal for LensOS)

### 1. One line per product
- “Create at the highest level.” · “Get work done. Faster.” · “Generate stunning content easily.”
- **LensOS:** One outcome in the hero. Already: *operating system behind the shoot* + **Open Pick**.

### 2. Product-in-the-hero
- Real UI / photo inside the marquee, not only abstract brand film.
- **LensOS:** Keep card + RUN + metrics mock. Prove the tool before pricing.

### 3. Low-friction start
- Primary CTA is always **try / free trial / create**, never “read our vision.”
- **LensOS:** Single CTA **Open Pick** (local now; trial later). No survey wall.

### 4. Role doors without forcing everyone through one story
- Students · business · individuals — different merch paths, same brand.
- **LensOS V1:** One door (working photographer / sports / volume). Segment soup after PMF.

### 5. Platform gravity
- Wins by **ecosystem** (LR ↔ PS ↔ mobile ↔ cloud), not one feature.
- **LensOS:** Gravity = **Import → Pick → Adobe → Send**. Explicit **exit to Lightroom**. Never pretend we are Photoshop.

### 6. Named proof, not generic “trusted by millions”
- Filmmaker / realtor / creator quotes with faces → plans.
- **LensOS:** Real pilot names when we have them. No fake social proof.

## What Adobe does poorly / leaves open (our wedge)

| Adobe reality | LensOS answer |
|---------------|----------------|
| Homepage sells **everything** (Firefly, Acrobat, brand visibility, education) | Site sells **one spine** for lazy shooters |
| Subscription forever + price climb (Photo plan ~$12–$20+/mo; CC Pro much higher) | Local-first V1; pay when shipping jobs (later) |
| Lightroom pushed as **complete workflow hub** (organize + develop + now **Assisted Culling GA**) | Own **fast pick + handoff + client** only — still faster, still dedicated |
| Cull is free *if* you already pay CC — but quality reports mixed (“too fussy / too generous”) | Cull is the **product**, not a checkbox inside edit |
| Client delivery is **not** Adobe’s crown jewel | **Send** is our second crown (Pixieset-shaped gap) |
| AI noise they didn’t ask for (credits, Firefly front-and-center) | Optional assist; keyboard + human final call first |

Photographers leave Adobe signal (2025–26): **cost, bloat, AI tax** — not “they can’t edit RAW.”

## Threat: Adobe Assisted Culling (GA 2026)

Adobe blog (Jun 2026): Lightroom **Assisted Culling** generally available — Face View, Eyes Open / Eye Sharpness, filters, dials, overrides. Positioned as turning LR into the full hub “from culling to compositing.”

| If we ignore this | If we respond correctly |
|--------------------|-------------------------|
| “Why pick another tool? Cull is free in Photo plan.” | Be **faster + clearer for volume** (sports / weddings / same-night) |
| Feature parity race with Adobe | **Spine:** pick → keepers ZIP Adobe understands → **client link** LR still doesn’t own |
| Copy “AI cull” marketing | Ship **keyboard + stacks + 2-up compare** that pros trust |

**CTO rule:** Adobe owns *marginal* cull for people already inside LR. We own **decision velocity + delivery** for people who hate waiting on the hub.

## Website lessons for LensOS landing

| Do | Don’t |
|----|--------|
| Dark premium, huge type, product mock | Multi-page prototype maze |
| One CTA | Pricing essays, contributor program, economics calculator on day one |
| Outcome headline | “Prompt-first workspace” jargon walls |
| Show numbers (4,128 in → link live) | Fake social proof without pilots |
| Honest Adobe handoff | “Replace Lightroom” |
| Adobe-tier *presentation* | Adobe *catalog sprawl* |

Adobe can afford catalog sprawl. **We cannot.** Lazy visitor = one scroll, one button.

## Product positioning (CTO lock)

```
Craft (all of it):     shoot + edit. Nothing else is "creating."
Adobe owns:            edit / pixels / develop / industry files
Camera owns:           shoot
LensOS owns:           Pick (volume decision speed) + Send (client path) around Adobe
```

That’s the whole pitch. Don’t pad it.

Never compete on color science or Firefly.  
Win = **same-night card → selects → client link** so shoot + edit get the hours back.

**Spine stays non-negotiable:**
```
Import → Pick (cull) → Adobe (keepers) → Send (client gallery)
```

## What to build next (from this learn)

1. **Landing** — simplified one-pager; stay Adobe-tier presentation, anti-Adobe scope.  
2. **Pick** — keyboard cull + stacks + 2-up compare so LR isn’t the bottleneck.  
3. **Handoff** — ZIP + ratings Adobe already understands (honest exit).  
4. **Send** — gallery link (Adobe still weak).  
5. **Later** — usage pricing that scales with jobs; only then free-trial merch language.
